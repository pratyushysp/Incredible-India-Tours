# 🌏 Incredible India Tours — Travel & Tourism Website

A responsive, multi-page **Tours & Travel website** built as a B.Tech Minor Project.

## 📋 Project Overview

This is a complete travel service website for **domestic Indian tourism**, allowing users to explore tour packages, destinations, pricing, itineraries, and activities — all within India.

## 🗺️ Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero section, category cards, featured packages, testimonials |
| Packages | `pages/packages.html` | All 6 tour packages with full itineraries, prices, activities |
| Destinations | `pages/destinations.html` | Visual grid of 9 top Indian destinations |
| About | `pages/about.html` | Company story, team, values, stats |
| Contact | `pages/contact.html` | Booking enquiry form, contact info |

## ✈️ Featured Tour Packages

1. **Royal Rajasthan & Agra** — Family · 7 Days · ₹32,999/person
2. **Kerala Backwaters Bliss** — Couple · 6 Days · ₹28,500/person
3. **Manali–Spiti Adventure** — Friends · 8 Days · ₹24,999/person
4. **Goa Beach Party Escape** — Friends · 5 Days · ₹18,500/person
5. **Andaman Island Romance** — Couple · 7 Days · ₹42,000/person
6. **Jim Corbett Wildlife Safari** — Family · 4 Days · ₹22,500/person

## 🛠️ Technologies Used

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — Navbar scroll, filter tabs, form handling, scroll reveal
- **Google Fonts** — Playfair Display, Raleway, Dancing Script

## 📁 Folder Structure


## ✨ Features

- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Sticky navbar with scroll effect
- ✅ Hero section with animated stats
- ✅ Filter packages by type (Family / Couple / Friends)
- ✅ Complete day-by-day itineraries for each package
- ✅ Activities, inclusions, pricing for every package
- ✅ Scroll-triggered reveal animations
- ✅ Working booking enquiry form
- ✅ Newsletter subscription section
- ✅ Destinations visual gallery
- ✅ About page with team & company values

## 🚀 How to Run

1. Clone this repository
2. Open `index.html` in any browser
3. No server or build tools required — pure HTML/CSS/JS!

```bash
git clone https://github.com/yourusername/india-tours.git
cd india-tours
# Open index.html in browser
```
